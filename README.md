# **Focus Span — Student Productivity Dashboard**

Focus Span is a static productivity dashboard built using HTML, CSS, JavaScript, and React (CDN version).

This project runs using **live-server** for local development.

---

## 🚀 How to Run the Project

### **1. Install dependencies**

```sh
npm install
```

## Running on live server

npm start

## Stopping the server

Ctrl + C
